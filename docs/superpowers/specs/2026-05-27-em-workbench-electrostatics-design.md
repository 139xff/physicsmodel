# EM Workbench: 静电场模块设计规格

## 1. 产品定位

`EM Workbench / 电磁学工作台` 是面向大学电磁学学习者的网页交互实验平台。它强调自主建模、观察和分析，而不是预设的课程步骤、强制预测或答题闯关。

产品长期可扩展到静磁场、电磁感应与电磁波，但第一版只建设 `静电场模块`，集中解决一个问题：用户如何通过自由组合电荷分布，直观且可量化地理解电场与电势的空间结构。

## 2. 设计原则

- `自主探索优先`：进入应用后直接使用工作台，学习资料和任务均为可选辅助。
- `同一场景，多种观察`：二维和三维视图共享对象、参数、探针和计算状态。
- `物理图像与数值分析并重`：既显示场的空间结构，也支持读取与比较数值。
- `交互流畅且结果可信`：通过实时预览与精确计算两档模式平衡速度和精度。
- `为后续电磁模块留边界`：静电对象、场求解、可视化和分析工具保持清晰分层。

## 3. 首版范围

### 3.1 包含内容

- 统一的静电场工作台页面。
- 点电荷及连续带电对象的自由添加、编辑与组合。
- 所有场景均支持 `2D / 3D` 视图切换。
- 电场、电势相关的可视化图层与测量分析工具。
- 实时预览与高精度结果两档计算体验。
- 可载入、可继续编辑的经典预设场景。
- 少量可选探索任务与按需理论说明。

### 3.2 暂不包含

- 用户账号、学习进度、成绩或排行系统。
- 教师管理、课堂投放或多人协作功能。
- 静磁场、电磁感应、电磁波模块。
- 完整符号推导引擎。
- 面向科研的数据导出或高性能大规模求解。

## 4. 用户与使用场景

主要用户是已经接触或正在学习大学电磁学的学生。用户可能出于以下目的使用工作台：

- 自由搭建电荷系统，观察电场与电势如何随配置变化。
- 载入典型模型，验证课程中的对称性结论或公式直觉。
- 在三维空间中理解圆环、圆盘、平面与球壳的场结构。
- 通过探针和采样曲线，对比不同电荷分布的数值特征。
- 主动选择探索任务，检验自己的构造与分析能力。

## 5. 核心场景模型

### 5.1 可添加物理对象

用户可在同一个三维场景内自由添加、移动、旋转、组合下列静电源：

| 对象 | 主要参数 | 备注 |
| --- | --- | --- |
| 点电荷 | 位置、总电荷量 | 最基础的离散电荷源 |
| 均匀带电线段 | 位置、方向、长度、线电荷密度或总电荷 | 支持任意空间取向 |
| 均匀带电圆环 | 圆心、法向、半径、线电荷密度或总电荷 | 支持任意空间取向 |
| 均匀带电圆盘 | 圆心、法向、半径、面电荷密度或总电荷 | 支持任意空间取向 |
| 均匀带电平面 | 中心、法向、显示尺寸、面电荷密度 | 表示理论无限大平面；显示尺寸仅用于可视化 |
| 均匀带电球壳 | 球心、半径、面电荷密度或总电荷 | 旋转对其物理状态无影响 |

### 5.2 通用对象操作

- 添加、选择、复制、隐藏、删除对象。
- 平移对象；对具有方向的对象进行旋转。
- 修改尺寸及电荷相关参数。
- 通过对象列表快速定位和管理场景内的电荷源。
- 重置当前场景或载入新的预设配置。

### 5.3 预设场景

经典模型以可编辑预设场景呈现，而非封闭的单独课程页。首版预设可包括：

- 单点电荷与电偶极子。
- 同号双电荷与零场区域探索。
- 带电线段的近场与远场。
- 带电圆环及其轴线分布。
- 带电圆盘逐渐逼近无限平面。
- 均匀带电球壳的内部与外部场。

用户载入预设后可以继续修改对象或叠加其他电荷源。

## 6. 工作台界面结构

首版采用单工作台结构，不以章节或教学流程组织页面。主要区域包括：

### 6.1 场景工具区

- 添加各类电荷对象。
- 对象列表与当前选中对象的参数编辑器。
- 预设场景入口。
- 场景重置与必要的撤销/重做能力。

### 6.2 主视图区

- 展示当前 `2D` 或 `3D` 场景。
- 支持视角缩放、平移；三维模式下支持旋转观察。
- 显示对象本体、场可视化图层与探针。
- 置于明显位置的 `2D / 3D` 切换按钮。

### 6.3 图层与分析区

- 可视化图层开关与参数。
- 探针数据。
- 沿线采样曲线。
- 单个对象对探针位置的贡献分解。
- 当前计算质量和计算状态提示。

### 6.4 可选辅助区

- 公式与关键推导摘要抽屉。
- 可选探索任务列表。
- 用户主动请求后出现的提示与解释。

## 7. 2D 与 3D 视图

### 7.1 状态一致性

`2D / 3D` 切换是一级交互。两种视图必须共享：

- 电荷对象及其参数。
- 探针位置与读取结果。
- 当前选定的预设或用户自建场景。
- 图层偏好中适用于两种视图的部分。
- 当前计算模式和结果版本。

切换视图不能重置实验，也不能悄然改变物理模型。

### 7.2 2D 视图

二维视图用于精细分析。由于场景本身可能是三维的，用户需要能够选择或移动一个观察平面，在该平面上显示：

- 平面内电场矢量采样。
- 场线在观察平面中的表达，适用于可解释的切面观察。
- 等势线。
- 电场强度或电势热力图。
- 探针和沿线采样。

对于不关于观察平面对称的三维场景，二维视图表达的是该平面上的采样结果，而不是声称完整场线始终位于该平面。

### 7.3 3D 视图

三维视图用于空间构建和观察，支持：

- 真实几何形式的点、线段、圆环、圆盘、平面与球壳显示。
- 三维对象移动、旋转和参数调整。
- 三维电场矢量采样。
- 三维场线表达。
- 简化的等势面或空间颜色表达。
- 三维探针放置与读取。

三维视图的首要目标是交互理解与合理性能，不以高密度科研级可视化为首版要求。

## 8. 可视化与分析工具

### 8.1 可视化图层

用户可独立开关和调节以下图层：

- 电场矢量图层。
- 场线图层。
- 二维等势线或三维简化等势面图层。
- 场强热力图或电势颜色图层。

系统应避免默认同时开启过多层造成视觉混乱。默认组合应突出对象本体与一种主要场表达，其余由用户开启。

### 8.2 探针

用户可在空间放置探针并读取：

- 三维坐标。
- 总电势 `V`。
- 总电场向量 `E`。
- 电场大小 `|E|`。
- 每个电荷对象对该位置的电势和电场贡献。

对于连续带电对象，贡献分解以整个对象为单位，不显示每个内部离散积分单元。

### 8.3 沿线采样

用户可设置一条空间采样线，并选择查看：

- `V` 随位置变化的曲线。
- `|E|` 随位置变化的曲线。
- 电场在采样线方向上的分量曲线。

此工具特别适合分析圆环轴线、圆盘法线方向、平面法线方向以及球壳径向结果。

## 9. 计算模式与物理可信度

### 9.1 两档计算模式

工作台提供两种计算质量状态：

#### 实时预览

- 在对象拖动、旋转或参数连续修改时运行。
- 优先保证交互反馈及时。
- 对连续带电对象采用较低密度数值离散或适当的快速表达。
- 对场线、等势面和热力采样使用较低分辨率。

#### 精确计算

- 在用户停止交互后自动触发细化，或由用户主动点击触发。
- 提高连续带电对象的积分/离散精度。
- 提高探针、沿线采样和图层结果质量。
- 为复杂场景提供清晰的计算进度或状态反馈。

### 9.2 状态表达

界面需要明确显示结果状态：

- `实时预览`
- `正在精算`
- `高精度结果`
- 必要时显示复杂度过高、分辨率已自动调低等提示

这样用户能够区分交互预览和最终分析结果，不会误读数值精度。

### 9.3 理论模型约定

- 平面对象在物理模型上表示无限大均匀带电平面；用户调整的平面大小只影响屏幕中的显示范围。
- 点电荷附近存在理论奇点；系统应避免在电荷位置本身显示无意义的无限数值，并给出适当提示。
- 连续带电对象叠加时，高精度结果仍是面向教学与探索的数值近似，不承诺科研级误差控制。

## 10. 自主探索辅助

### 10.1 理论抽屉

理论内容默认收起，用户主动打开后可看到：

- 当前选中对象的公式与参数含义。
- 典型对称性结论。
- 积分或高斯定律的关键思路摘要。
- 当前预设场景值得观察的现象提示。

该区域提供参考，不强制用户阅读或按步骤操作。

### 10.2 探索任务

任务作为可选功能存在，不影响自由工作台的主要路径。可包含：

- 构造某个指定位置的零场点。
- 构造电偶极或多极特征场。
- 调整对象，让某一小区域内的电场尽可能均匀。
- 比较不同半径圆盘与无限大平面的轴线场。
- 组合球壳与外部电荷，观察对称模型被扰动后的分布。

任务反馈以达标情况和物理解释为主。提示仅在用户请求时显示，并可分层展开。

## 11. 系统边界与扩展方向

### 11.1 首版内部模块边界

实现时应将功能分为下列职责清晰的单元：

- `场景模型`：保存电荷对象、参数、探针、采样线和预设。
- `静电求解`：按对象类型计算 `V` 与 `E`，并支持质量等级。
- `可视化采样`：为二维与三维图层准备所需采样结果。
- `交互编辑`：对象添加、选中、移动、旋转、参数修改和视图切换。
- `分析工具`：探针、贡献分解和曲线采样。
- `辅助内容`：预设、任务和理论抽屉。

求解层应与可视化表现解耦，以便未来磁场模块复用场景、视图和分析框架。

### 11.2 未来扩展

- 静磁场：电流元、直导线、电流环、螺线管。
- 电磁感应：随时间变化的磁通、运动导体和感应电动势。
- 场传播与电磁波。
- 用户保存、分享自定义场景。
- 更高级的数值精度设置与数据导出。

这些内容不进入首版承诺。

## 12. 质量与验证重点

首版需要重点验证：

- 基础模型的 `V` 与 `E` 计算是否符合已知解析结果或对称性结论。
- 同一场景在 `2D / 3D` 切换后参数、探针和结果状态是否一致。
- 实时预览在典型设备上是否足够顺滑。
- 精确计算结果是否稳定，并能清楚告知用户状态。
- 点电荷奇点、过高复杂度场景、不可用图层组合等边界情况是否有可理解的反馈。
- 默认界面是否支持自由探索，而不是把辅助任务或说明强加给用户。

## 13. 成功标准

当用户可以完成以下行为时，首版目标即得到满足：

- 从空场景开始，添加并编辑多种三维静电源。
- 一键在 `2D` 和 `3D` 观察之间切换，同时保持实验状态。
- 通过不同图层、探针和曲线查看场分布及数值结果。
- 感知实时预览与高精度计算的区别，并选择适合当前探索的结果。
- 载入典型预设或可选任务后，仍保持自由修改和继续探索的能力。
