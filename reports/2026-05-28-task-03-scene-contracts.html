Task 03: Typed scene contracts and source editing API

DONE Completed: 2026-05-28T09:01:32+08:00

Scope Delivered

  • Added Pydantic v2 editable scene contracts for point charges, line segments, rings, disks, infinite planes, and spherical shells.
  • Normalized nonzero orientation and normal vectors while keeping position and geometry fields explicit in SI units.
  • Enforced positive dimensions, finite charge values, and an exactly-one total-charge-or-density rule where physically meaningful; infinite planes require surface density and remain physically infinite.
  • Added stable preset summary/detail endpoints and a scene validation endpoint that returns normalized ordinary scene JSON without persistence or solver output.
  • Provided five editable presets: single point, electric dipole, charged ring axis, disk approaching plane, and spherical shell inside/outside.

Scope Deferred

  • Electrostatic potential and field solving remains Task 4 scope.
  • Shared 2D/3D browser interaction, source manipulation widgets, probes, overlays, and Playwright browser evidence remain later tasks.
  • No user accounts, persistence, collaboration, or saved custom scenes were introduced.
