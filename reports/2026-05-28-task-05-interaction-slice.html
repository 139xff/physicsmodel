Known Risks And Limitations

  • 3D rendering is intentionally basic and rerenders on state changes; it is suitable for this slice but not optimized for large source counts.
  • Inline source editing has no deletion or validation messaging beyond API failure status.
  • Ring source editing exposes radius and charge but not normal; arbitrary normals can be rendered from scene data but are not yet user-editable in the browser.
  • The stale-response guard ignores out-of-date successful responses but does not cancel in-flight fetches.
  • Playwright emits deprecation warnings from uvicorn/websockets dependencies during the in-process test server.
