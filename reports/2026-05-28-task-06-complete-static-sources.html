Known Risks And Limitations

  • Rapidly editing a direction vector through zero can briefly produce a validation failure status until the next nonzero component update restores a valid solver request.
  • The overlay uses fixed 5x5 samples at the probe z-plane and does not adapt density or domain to the current source extent.
  • Refined quality with many numerical sources may be noticeably slower because both probe and overlay requests go through the authoritative Python solver.
  • The stale-response guard ignores outdated responses but does not cancel in-flight fetches.
  • Playwright emits uvicorn/websockets dependency deprecation warnings during the in-process test server.
