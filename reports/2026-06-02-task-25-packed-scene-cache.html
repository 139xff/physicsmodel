Implementation notes

  • The compiler reuses the scalar solver's charge conversion helpers so both paths retain identical source semantics.
  • All published arrays have writeable=false to keep cache entries safe for concurrent readers.
  • Source indexes remain aligned with the original Pydantic scene ordering for later contribution aggregation.

Known risks or limitations

  • The cache is not yet connected to the runtime status API.
  • Concurrent first access may compile the same scene more than once before one result is retained; correctness is unaffected.
  • The suite still reports two upstream WebSockets deprecation warnings.
