Diagnostic notes

  • Numba could not unify float32 state arrays with float64 arrays created by RK4 expressions such as dt_s / 2.0. The kernel now receives typed half-step, one-sixth-step, and factor-two constants matching the packed-scene precision.
  • The benchmark warms the compiled trajectory once, measures ten compiled 400-step preview trajectories, then measures one scalar 400-step preview trajectory against the same representative scene.

Known risks or limitations

  • Trajectory integration remains single-particle and sequential. This is intentional for correctness and low overhead; multi-particle integration would need a separate parallel dispatch policy.
  • Explicit CUDA trajectory requests currently return CPU JIT results with a fallback reason because no CUDA trajectory kernel is exposed.
  • The suite still reports two upstream WebSockets deprecation warnings.
