Known risks or limitations

  • Warm-up is process-local and starts once when compute status is first requested. It does not persist compiled state across Python process restarts.
  • The desktop queue intentionally serializes compute work on one worker so Qt UI event handling remains responsive and result ordering stays predictable.
  • Desktop and CUDA packages remain optional extras; the default installation continues to run CPU-only without them.
