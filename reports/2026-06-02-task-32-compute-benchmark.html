Diagnostic notes

  • The first trajectory benchmark started too close to a point charge, making 400-step float32 preview integration sensitive to tiny perturbations. The stable benchmark trajectory now starts at (0, 0.20, 0) m; its 400-step position deviation is about 9.1e-8 m.
  • Explicit CUDA field-line timing remains visible in the JSON artifact: about 1271 ms for the representative workload. Automatic dispatch correctly chooses CPU JIT for this interactive workload.

Known risks or limitations

  • The 2048-candidate field-line CUDA threshold is intentionally conservative because tested interactive workloads favored CPU. Explicit CUDA can be benchmarked for larger custom scenes.
  • CUDA package synchronization is unusually slow on this workstation even when package files eventually install correctly.
