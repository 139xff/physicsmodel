Completed: 2026-06-11 01:20:47 +08:00

Scope Delivered

  • Reduced pan and zoom stutter while electric field lines are visible.
  • Changed 2D wheel and pan interaction to update the existing SVG viewBox directly instead of rebuilding all field line paths on every input event.
  • Deferred field line layer rebuild and backend field line refresh until 160 ms after interaction settles.
  • Invalidated stale in-flight field line requests during view interaction so delayed responses do not force an immediate heavy redraw.
  • Added browser regression coverage for deferred field line layer rerendering.
  • Updated static asset cache keys so browsers load the performance fix.

  • Further optimization could cache generated field line path strings per request and only remap labels/arrows, but the current fix removes the input-event redraw bottleneck.

Known Risks and Limitations

  • During the active pan or zoom burst, axes and field line samples are temporarily scaled by the current SVG viewBox; final regenerated field lines arrive after interaction settles.
  • Extremely large mixed-source scenes may still benefit from additional path-string caching, but repeated input-event DOM rebuilds are removed for the field-line case.
