静电场仿真与可视化平台设计报告

面向大学电磁学学习的交互式静电场建模、计算与可视化系统

报告范围说明：本文只讨论静电场仿真与可视化，包括点电荷、带电线段、带电圆环、带电圆盘、无限带电平面、带电球壳、探针测量、电场线、等势线、试探电荷运动和散射实验。磁场模块、电磁感应模块以及完整 Maxwell 方程组数值求解平台不纳入本报告内容。

摘要

本作品是一个可由操作者自由改变参数的静电场仿真与可视化平台。平台允许用户在同一场景中组合多种电荷模型，实时观察电场、电势、电场线、等势线和试探电荷轨迹，并通过探针读取定量结果。系统以库仑定律、电势叠加原理和连续带电体积分为物理基础，使用 Python 后端完成权威数值计算，前端负责场景编辑、二维和三维展示。其目标不是替代严格推导，而是把抽象公式转化为可操作、可比较、可验证的物理图像。

1. 选题意义与目标定位

静电场是大学电磁学中的基础内容。学生通常先从点电荷、电偶极子、均匀带电线段、带电圆环、带电圆盘、无限平面和球壳等模型入手，再学习叠加原理、对称性分析和电势概念。传统学习方式容易把公式和空间图像割裂：公式可计算，但场线、等势线和三维结构不够直观；图像可观察，但往往缺少可调参数和定量验证。

本平台的目标是构建一个开放式静电场工作台，使操作者能够自主设置电荷源类型、位置、尺寸和电荷量，并可视化输出仿真结果。平台强调三个目标：

  • 自主建模：用户从源库中选择模型，自由组合不同电荷分布，而不是只能观看固定演示。
  • 可视化理解：通过二维切片、三维视图、电场线、等势线和轨迹动画形成空间直觉。
  • 定量验证：使用探针、贡献分解和散射结果，将图像观察与物理数值联系起来。

2. 物理原理

2.1 点电荷、库仑定律与电势

对于位于 r0 的点电荷 q，采样点 r 处的电势和电场为：

V(r) = k q / |r - r0|
E(r) = k q (r - r0) / |r - r0|3
k = 1 / (4π ε0)

多个电荷源同时存在时，系统使用叠加原理，将每个源的电势和电场矢量贡献相加：

Vtotal = Σ Vi，Etotal = Σ Ei

2.2 连续带电体的积分思想

带电线段、带电圆环和带电圆盘不能简单视为一个点电荷，系统将它们离散为多个小电荷元，并对每个电荷元的库仑贡献求和。其数学思想是：

V(r) = ∫ k dq / |r - r'|
E(r) = ∫ k (r - r') dq / |r - r'|3
模型 计算方法 物理含义
带电线段 沿线段方向使用 Gauss-Legendre 积分节点。 把均匀线电荷分解为一系列小电荷元。
带电圆环 按方位角均匀分段积分。 每个小弧段贡献一个等效电荷元。
带电圆盘 径向使用 Gauss-Legendre 节点，角向均匀分段。 在极坐标下对圆盘面积元积分。

2.3 高对称模型

对于无限带电平面和均匀带电球壳，系统使用解析模型。无限平面的电场大小为 |E| = |σ| / (2 ε0)，方向沿平面法向两侧相反。球壳内部电场为零，外部等效为位于球心的点电荷；内部电势等于壳面电势。

2.4 电场线、等势线与试探电荷

电场线方向与局部电场方向一致，正电荷发出、负电荷终止；等势线表示电势相同的点集合，并与电场方向正交。平台在二维视图中计算场线轨迹，并在电势采样网格上提取等势线。

试探电荷运动使用 F = qE 与牛顿第二定律 a = F/m。轨迹积分使用四阶 Runge-Kutta 方法，以减小普通 Euler 方法在非均匀场中的累积误差。散射实验则以库仑斥力和 Rutherford 散射关系为依据，用来展示带电粒子在电场中的偏转。

4. 功能设计

4.1 场源库

场源 主要参数 用途
点电荷 位置 x/y/z，电荷量 q 理解库仑场、单源径向分布、电偶极基础。
带电线段 位置、方向、长度、总电荷或线密度 展示连续线电荷和有限长度边界效应。
带电圆环 圆心、法向、半径、总电荷或线密度 分析环轴线上场强、电势和对称性。
带电圆盘 圆心、法向、半径、总电荷或面密度 比较有限圆盘与无限平面的近似关系。
无限带电平面 位置、法向、显示范围、面密度 验证高斯定律得到的均匀电场结论。
带电球壳 球心、半径、总电荷或面密度 展示壳内电场为零、壳外等效点电荷。

4.2 可视化与交互

2D 视图

用于平面分析，显示源模型、电场线、等势线、探针和试探电荷轨迹。适合观察对称性、零场区域和局部变化。

3D 视图

用于空间理解，显示点、线段、圆环、圆盘、平面和球壳等几何形态，并支持视角旋转观察。

探针测量

用户输入探针坐标后，平台返回该点的电场向量、电场强度、电势以及各源贡献。

计算质量

快速预览用于交互响应，精细计算提高积分节点数量和结果质量，便于对比精度。

4.3 典型应用场景

  • 构造电偶极子，观察电场线从正电荷出发并终止于负电荷。
  • 改变圆环半径和探针位置，比较轴线上电势与场强变化。
  • 将圆盘半径逐渐增大，观察其场分布向无限平面结果逼近。
  • 把探针放入球壳内部，验证内部电场为零但电势不一定为零。
  • 发射试探电荷，观察电荷符号、质量、初速度对运动轨迹的影响。
  • 运行散射实验，比较冲量参数与散射角之间的关系。

5. 使用方法与参数设置

5.1 启动方式

开发环境中使用项目本地 uv 启动：

.\.tools\uv\uv.exe sync
.\.tools\uv\uv.exe run uvicorn em_workbench.app:app --reload

启动后在浏览器打开本地服务地址。打包版本可通过 Windows 便携包运行，无需用户手动启动服务器。

5.2 基本操作流程

  1. 从源库选择点电荷、带电线段、带电圆环、带电圆盘、无限平面或球壳。
  2. 设置位置、方向、半径、长度、电荷量或电荷密度等参数。
  3. 在 2D 或 3D 视图中观察场源形状和空间分布。
  4. 开启电场线或等势线图层，观察场结构。
  5. 移动探针并读取 V、E、|E| 以及各源贡献。
  6. 切换快速预览和精细计算，比较复杂连续源附近的结果差异。
  7. 根据需要运行试探电荷运动或散射实验。

5.3 参数单位

参数 界面输入单位 后端计算单位
位置、长度、半径 厘米 cm 米 m
电荷量 库仑 C 或纳库仑 nC 库仑 C
质量 毫克 mg 千克 kg
速度 厘米/秒 cm/s 米/秒 m/s
电场、电势 结果显示 V/m 与 V

6. 结果的物理意义与有效性分析

6.1 结果含义

平台输出的电场向量表示单位正试探电荷在该点受到的电力方向和大小；电势表示单位正电荷在该点具有的静电势能。电场线反映电场方向结构，线的密集程度可作为场强大小的直观参考；等势线反映电势分布，同一条等势线上电势相同。

6.2 合理性验证

项目测试中已经覆盖下列物理一致性：

  • 单点电荷结果符合解析库仑公式。
  • 多点电荷满足线性叠加。
  • 对称电荷系统在对称方向上的分量符合预期。
  • 带电圆环轴线结果与已知解析趋势一致。
  • 连续带电体积分节点数量随预览/精细模式改变。
  • 点电荷奇点、线段和圆环近几何位置会返回警告而不是静默给出误导性结果。
  • 电场线种子分布、平滑性、截断数量和源间连接有专门测试。
  • Rutherford 散射角方向和冲量参数关系有数值验证。

6.3 有效性

对于课堂学习和自主探索，本系统可以有效展示静电场中“源参数改变 -> 场分布改变 -> 探针数值改变 -> 轨迹响应改变”的因果链。它尤其适合解释叠加原理、连续带电体积分、高对称模型和散射偏转等内容。

6.4 局限与改进思路

  • 点电荷和连续带电体几何位置附近存在理论发散，平台只能给出警告和数值截断，不能消除物理奇点。
  • 线段、圆环、圆盘采用数值积分，离散节点越多越准确，但计算成本也增加。
  • 二维视图是平面采样，不代表所有三维场线都真实限制在该平面内。
  • 电场线和等势线是教学可视化结果，不等同于严格误差可控的科研绘图。
  • 当前报告不覆盖磁场、电磁感应和完整 Maxwell 方程组数值求解，这些属于后续扩展方向。

7. 可拓展性设计

项目将场景契约、求解器、计算后端、API 和前端渲染分层。静电求解模块独立于 FastAPI 与界面，便于测试和替换；前端通过 JSON API 获取结果，不直接承担权威物理计算。这样的架构使后续可以继续增加新的静电源、采样工具、导出功能或更高性能后端。 

场景模型 Scene
  ├─ 源参数：位置、方向、尺寸、电荷
  ├─ API 契约：请求和响应均可序列化
  ├─ 物理求解：独立模块，可单元测试
  ├─ 计算后端：CPU/CUDA/标量策略可切换
  └─ 前端渲染：只消费计算结果，不改写物理模型

10. 结论

本平台围绕静电场核心知识建立了可操作的仿真/模拟程序。它允许用户改变参数，观察并测量电场、电势、场线、等势线和带电粒子运动，使抽象公式转化为可验证的交互实验。作品的主要价值在于把库仑定律、叠加原理、连续积分和对称性结论统一到同一个工作台中，既保留数值计算的严谨性，也提供直观的教学效果。

从当前实现看，本系统已经具备静电场自主建模、数值求解、二维/三维展示、探针测量、轨迹模拟、散射实验和性能后端状态显示等能力。其局限主要来自奇点处理、连续体离散误差和教学可视化精度边界。后续可在保持静电模块稳定的基础上，进一步完善数据导出、误差估计、更多预设场景和更细致的用户交互。
